Your live sessions need a trusty sidekick.

Live session

Beside Claude as it works.

Self-Reflect works beside your Claude Code session on every turn. Hooks run on each prompt. A heads-up band brings in the history of a file you name. The pane shows where the work stands. It also checks old conclusions against git, and it can bring back turns a compaction replaced.

Read back

Read the turns a compaction replaced.

Compaction is one moment in a session, and Self-Reflect covers it too. After a compaction, a receipt points Claude to the original turns. Claude can use csr_transcript to read a slice of the exchange and check exactly what you asked. It even keeps the copies Claude Code deletes.

Recap

Pick up where you left off.

When a session starts or resumes with enough evidence, Claude gets one paragraph covering the intent, what got done, what was settled, what is open, and any next step the evidence supports. Self-Reflect builds it from commits, tasks, and your own turns without calling a model.

How it works

An engine that checks. A Claude that looks back.

Self-Reflect joins two parts. The engine is deterministic Rust: the same input gives the same output. Claude does the reflecting. Each part checks the other.

Where it runs

All local. Your code and history stay on your machine.

  • One binary, one daemon. The index is a local SQLite file and a local vector index under ~/.claude-self-reflect.
  • Embeddings run here. The embedding model (all-MiniLM-L6-v2, about 90 MB) downloads once, then runs on your machine through FastEmbed.
  • Model calls go only to Claude. They are background claude -p calls on your plan. If you set your own API key, the optional batch lane uses that key instead. CSR_NO_AI_NARRATIVES=1 stops them. CSR_NO_DREAMING=1 stops dreams.
  • Quiet by design. The daemon works when something happens, then rests. Companion panes rest too.

  1. Wakes

    A Claude Code hook asks a question, or a transcript file changes. Slow timers catch up on the rest.

  2. Works

    It imports, searches, and checks git. Dreams wait for Claude Code to be quiet, 30 minutes by default.

  3. Rests

    There is no busy loop. Between events it sleeps.

Panes you are not using rest.

When a pane's session is quiet and nobody is looking at it for 5 minutes, it rests. It clears its pictures and prints a short card in words. It then swaps itself for a small waiting process on the same pid. That process holds no fonts, no database, and no pictures. A key, a click, a resize, a change in the transcript, a herdr focus, or a terminal focus wakes it. Set CSR_PANE_IDLE_MINS to change the delay. Set it to 0 to turn resting off.

The pane

The pane lives in herdr.

herdr is a terminal workspace manager for AI coding agents. Claude Code runs in one pane. The Self-Reflect companion runs in the pane beside it.

  • A pane beside the session. The companion sits next to Claude and never covers it.
  • Focus events that wake the pane. herdr tells the pane when you look at it, so a resting pane wakes at once.
  • Whether Claude is working. The pane rests only when herdr says Claude is idle and unfocused.
  • Pictures. The pane draws charts and cards as pictures, and herdr shows them in the split.

brew install herdr then csr-engine companion serve. The pane needs Claude Code 2.1.296 or later.

What stays yours.

  • One Rust binary. No cloud, no Docker, no Python, no database server.
  • Consent first. Setup asks before it turns anything on.
  • Private tags. Text inside <private> tags never reaches the index or the mirror.
  • Secrets redacted. Keys and tokens become [secret redacted: <kind>] before indexing or mirroring.
  • No prompt text in logs. Timing lines keep counts and a salted hash, with the salt in a local 0600 file.
  • Loopback journal. The journal listens on loopback, requires CSRF tokens for changes, and serves pages with default-src 'none'.
  • Filters its own echoes. [CSR text] ranks below your words and stays out of recaps.
  • Trust labels. Model-written context carries a [briefing: model-derived, trust=…] label.
  • Local permissions. Companion storage uses 0700 for directories and 0600 for files.

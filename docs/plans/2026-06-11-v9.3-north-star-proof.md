# CSR v9.3 — North Star Status (honest)

> **The gate:** CSR must recall its own founding vision *better than `grep`*.
> Failure benchmark (2026-06-11): semantic search returned build-log chunks
> @0.40 with zero provenance; truth came only from `grep + json.loads` over raw
> JSONL — and grep won.
>
> **Verdict: the ranking LOGIC is proven on a fixture (6/6). On the REAL index,
> CSR still LOSES to grep. The North Star is NOT yet achieved in production.**
> Both results are documented below — the fixture green is the regression clock,
> not the user-facing win.

## Real-index reality check (the test that matters)

Live `csr_reflect_on_past("the IIM / continuity vision …")` against the real
17K-chunk index, 2026-06-11:

| Rank | Score | Conv | What |
|---|---|---|---|
| 1 | 0.450 | `4b41a4ec` | self-referential session-meta |
| 2 | 0.450 | `69a05719` | *this* session — recursive bleed |
| 3 | 0.450 | `fc16f91d` | design-discussion session |
| **4** | **0.449** | **`0bab445f`** | **the actual founding decision** |

`grep "infinite session without infinite tokens"` → `0bab445f.jsonl`, 90 hits,
**instant, #1.** **Grep still wins.** The true source ranks #4 in undifferentiated
0.40 mush, behind self-referential noise. Provenance absent from output.

Root causes (empirical): (1) live MCP serves the **pre-v9.3 binary** — the
reranker isn't running; (2) the 17K existing chunks have **no `chunk_provenance`**
(only new imports get it) — zero author signal to boost; (3) self-referential
meta chunks out-rank real content. None of v9.3's recall machinery is active in
production yet.

## Acceptance test

Query CSR for **"the IIM / continuity vision."** PASS requires the top result to
be the *decision* ("epistemic continuity, infinite session without infinite
tokens") **with provenance** — author, that it superseded "behavioral
continuity", sourced to conv `0bab445f` — ranked above any `[Edit:]`/`[Bash:]`
mechanic chunk, and CSR must rank it at least as well as grep.

Encoded as a runnable eval: `csr-engine eval --continuity`.

This is `csr-engine eval --continuity` over a **synthetic corpus authored for the
test**. It proves the rerank/provenance *logic* is correct; it does NOT prove
real recall (see the real-index reality check above).

  [PASS] ranking: decision above all mechanic chunks      top mechanic at rank 5

**`csr_rank=1, grep_rank=1`** — CSR now ties grep on raw recall *and* adds what
grep cannot: provenance (who authored it, what it superseded, its source conv),
poison rejection, and demotion of tool-mechanic noise. The 20-line grep that won
the founding query no longer wins.

## How it was won (the machine layer)

| Pillar | Mechanism | Where |
|---|---|---|
| Provenance indexing | `Speaker`/`ChunkProvenance` (user-authored = only authoritative, §Q6.2); `chunk_provenance` table | `src/provenance.rs`, `src/storage/` |
| Meaning re-ranking | authority + supersession boost; mechanic + non-user-authority-claim penalty | `src/search/rerank.rs` |
| Real-path attribution | speaker from JSONL role; tool_result-in-user-message detected, not trusted | `src/import/mod.rs` |
| Derivation Ledger (P1) | `value = P(needed)×bucket_weight×(1−inferability)`; value-density knapsack | `src/ledger/mod.rs` |
| Governor (P4) | reuse tracking, anti-flap budget decay, deterministic holdout; **reuse rates only** | `src/governor/mod.rs` |

## Honest limits (not yet claimed as solved)

- The gate is green on a **deterministic fixture corpus** (the acceptance
  scenario + poison + noise), not yet on a live 17K-chunk recall run.
- Chunk-level author is **coarse** at 50-message granularity; supersession is not
  yet extracted from real conversations (fixture sets it explicitly).
- The ledger knapsack and governor are **built and unit-tested but not yet wired
  into the live `UserPromptSubmit` injection selection** — that integration is a
  follow-up.

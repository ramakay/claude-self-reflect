# v9.4 — Conversation-Provenance Code Graph (CPG-in-SQLite)

**Status:** Proposed (final design, one-session deployable)
**Branch target:** `feat/v9.4-codegraph`
**Author:** Claude (Opus 4.8) — for Rama
**Date:** 2026-06-27

## 1. Thesis

CSR already has nodes (ast-grep symbols), a provenance edge (`chunk_provenance.supersedes`),
temporal deltas (`code_evolution`), and AST anchors (`episode_anchors`). What it lacks is a
**queryable code graph with edges** and a way to **inject a ranked slice** of that graph into
Claude's context.

The differentiator vs SCIP / aider / Glean: **every graph node and edge carries conversation
provenance**. A symbol isn't just `dispatch_hook defined at hooks/mod.rs:42` — it's
`dispatch_hook, last changed in conv_be… because the catch-all wrapper was added (Codex C-1)`.
That is the IIM ("Infinite Intelligent Memory") true-north: epistemic continuity, not just symbol lookup.

This design builds the **final** version in one session — not a stub.

## 2. What ships

1. **Schema** — `code_nodes`, `code_edges`, `code_node_rank`; `episode_anchors` becomes a view/feeder.
2. **Extractor** — extend `ast_analysis.rs` to emit nodes + edges (defines/calls/imports/references), with spans + body_hash.
3. **Resolver** — pragmatic two-pass name resolution (def table → ref match), same-file-priority then project-unique-name, unresolved edges retained + flagged.
4. **Ranking** — weighted PageRank over `code_edges`, persisted to `code_node_rank`.
5. **Provenance link** — every node/edge carries `conv_id` + `session_id`; join to `chunk_provenance` / `derivation_ledger`.
6. **Build triggers** — full build on import; incremental update on `PostToolUse` (Edit/Write) and file-watcher.
7. **MCP tool** — `csr_code_graph` (neighbors / callers / callees / impact / why-changed).
8. **Hook injection** — SessionStart + UserPromptSubmit inject ranked subgraph slice (≤500 tokens, framed as history).
9. **Eval** — `eval --codegraph` gate: resolution rate, rank stability, injection budget, query latency.

## 3. Schema (migrations.rs, new batch)

```sql
-- Graph nodes: every symbol CSR has seen, in code OR conversation.
CREATE TABLE IF NOT EXISTS code_nodes (
    id          TEXT PRIMARY KEY,          -- stable: sha1(repo|file|kind|name)
    repo        TEXT NOT NULL,
    project     TEXT NOT NULL,
    file        TEXT NOT NULL,
    lang        TEXT NOT NULL DEFAULT '',
    kind        TEXT NOT NULL,             -- function|type|method|import|module
    name        TEXT NOT NULL,
    fqname      TEXT NOT NULL DEFAULT '',  -- best-effort fully-qualified (module::name)
    body_hash   TEXT NOT NULL DEFAULT '',  -- detect change without diff
    span_start  INTEGER NOT NULL DEFAULT 0,
    span_end    INTEGER NOT NULL DEFAULT 0,
    -- provenance
    first_conv_id  TEXT NOT NULL DEFAULT '',
    last_conv_id   TEXT NOT NULL DEFAULT '',
    last_session_id TEXT NOT NULL DEFAULT '',
    last_seen   TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at  TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_code_nodes_name    ON code_nodes(name);
CREATE INDEX IF NOT EXISTS idx_code_nodes_file    ON code_nodes(project, file);
CREATE INDEX IF NOT EXISTS idx_code_nodes_repo    ON code_nodes(repo);

-- Graph edges: relations between nodes. conv_id = the conversation that asserted the edge.
CREATE TABLE IF NOT EXISTS code_edges (
    src_id      TEXT NOT NULL,             -- code_nodes.id
    dst_id      TEXT NOT NULL,             -- code_nodes.id (may be a placeholder if unresolved)
    kind        TEXT NOT NULL,             -- calls|imports|references|defines|implements|supersedes
    resolved    INTEGER NOT NULL DEFAULT 0,-- 1 = dst resolved to a real def, 0 = name-only
    weight      REAL NOT NULL DEFAULT 1.0, -- frequency / confidence
    conv_id     TEXT NOT NULL DEFAULT '',
    session_id  TEXT NOT NULL DEFAULT '',
    created_at  TEXT NOT NULL DEFAULT (datetime('now')),
    PRIMARY KEY (src_id, dst_id, kind)
);
CREATE INDEX IF NOT EXISTS idx_code_edges_src ON code_edges(src_id, kind);
CREATE INDEX IF NOT EXISTS idx_code_edges_dst ON code_edges(dst_id, kind);
CREATE INDEX IF NOT EXISTS idx_code_edges_unresolved ON code_edges(resolved) WHERE resolved = 0;

-- PageRank scores, recomputed on demand / batch.
CREATE TABLE IF NOT EXISTS code_node_rank (
    node_id     TEXT PRIMARY KEY REFERENCES code_nodes(id),
    rank        REAL NOT NULL DEFAULT 0.0,
    in_degree   INTEGER NOT NULL DEFAULT 0,
    out_degree  INTEGER NOT NULL DEFAULT 0,
    computed_at TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_code_node_rank_rank ON code_node_rank(rank DESC);
```

**Migration:** `episode_anchors` rows backfill into `code_nodes` (one-time, idempotent on `id`).
Keep `episode_anchors` writing for now (no breaking change); new graph reads from `code_nodes`.

## 4. Extractor — `src/extraction/codegraph.rs` (new)

Reuses `ast_analysis.rs` parsing (ast-grep / tree-sitter). Adds edge emission.

```
pub struct GraphFragment { nodes: Vec<NodeRow>, edges: Vec<EdgeRow> }

pub fn extract_graph_fragment(
    source: &str, lang: SupportLang, file: &str,
    repo: &str, project: &str, conv_id: &str, session_id: &str,
) -> GraphFragment
```

Per language, in addition to existing func/type/import kinds, capture **call sites** and
**reference identifiers**:

| Lang | call kind | ref kind | import resolve |
|------|-----------|----------|----------------|
| Rust | `call_expression` (callee `field_expression`/`identifier`/`scoped_identifier`) | `identifier` | `use_declaration` path tail |
| Python | `call` (`identifier`/`attribute`) | `identifier` | `import_from_statement` module+name |
| TS/TSX/JS | `call_expression` | `identifier` | `import_statement` specifiers |
| Go | `call_expression` | `identifier` | `import_declaration` |

For each definition node → `defines` edge (file-module node → symbol node), `body_hash` from
node text. For each call site → `calls` edge (enclosing-def node → callee name placeholder).
For each import → `imports` edge. Wrap all tree-sitter calls in the existing `catch_unwind`.

## 5. Resolver — `src/extraction/resolver.rs` (new)

Pragmatic, no external resolver crate (stack-graphs is too heavy for one session; documented as
future swap-in behind the same interface).

```
pub fn resolve_edges(conn: &Connection, project: &str) -> Result<ResolveStats>
```

Two-pass within a project scope:
1. Build `name -> [def node ids]` map from `code_nodes` where `kind in (function,type,method)`.
2. For each unresolved edge whose `dst` is a name-placeholder:
   - **same-file** def with that name → resolve (highest priority).
   - else **project-unique** name (exactly one def) → resolve.
   - else **ambiguous** → leave `resolved=0`, keep placeholder (still rankable by name).
3. Update `code_edges.resolved=1`, repoint `dst_id` to the real node id.

`ResolveStats { total, resolved, ambiguous, resolution_rate }` — surfaced in eval.
Cross-file ambiguity is acceptable: we optimize for the *ranked-slice injection* use case,
not compiler-grade correctness.

## 6. Ranking — `src/search/pagerank.rs` (new)

Weighted PageRank over the `calls` + `references` subgraph (imports excluded to avoid hub
domination). Damping 0.85, 30 iterations or L1 delta < 1e-6. Pure Rust, in-memory sparse
adjacency built from `code_edges`. Persist to `code_node_rank`. O(E) per iter — fine at repo scale.

Rank is the **injection priority signal**: when a slice exceeds budget, keep highest-rank nodes.

## 7. Build triggers (wiring)

| Trigger | Action | Where |
|---------|--------|-------|
| `import_conversations` | full extract → resolve → rank, after chunk import | `engine.rs` / `import/` |
| `PostToolUse` (Edit/Write) | incremental: re-extract touched file, upsert nodes/edges, mark dirty | `hooks/post_tool_use.rs` |
| File watcher batch | same as import for changed files | `engine.rs` watcher |
| `daemon` | periodic re-resolve + re-rank if dirty flag set | `daemon/` |

Incremental upsert keyed on `code_nodes.id` (stable hash) — `body_hash` change ⇒ bump
`updated_at`, `last_conv_id`. Edges replaced per (src file, conv) to avoid stale fan-out.

## 8. MCP tool — `csr_code_graph` (mcp/tools.rs)

```
csr_code_graph(
    symbol: Option<String>,   // name or fqname
    file:   Option<String>,
    mode:   "neighbors"|"callers"|"callees"|"impact"|"why_changed",
    depth:  u32 = 1,
    limit:  u32 = 20,
) -> ranked node list + edges + provenance (conv_id, last change reason from derivation_ledger)
```

- `impact` = transitive callers (blast radius of changing `symbol`).
- `why_changed` = join `code_nodes.last_conv_id` → `derivation_ledger` / reflection content.

Read-only, `annotations(read_only_hint=true, idempotent_hint=true)`.

### 8b. Rework `csr_search_by_file` into the file's immutable ledger (NEW — Rama's play)

**Current bug:** `tools::search_by_file` = `storage.fts5_search(file_path, ...)` — FTS5 over chunk
*content* for the path string. Porter tokenizer splits on `/` `.` `_`, so `ast_analysis.rs` never
matches → "No conversations found" even for heavily-edited files. It is fuzzy text search
masquerading as a file index. **Confirmed broken on this repo.**

**The play:** make `search_by_file` a deterministic structured query — the complete, append-only
history of a file. No embeddings, no fuzz. A file is an entity; its ledger is immutable.

Join sources (all already keyed by `file_path` / `file`):
- `code_evolution` (indexed `idx_code_evolution_file`) → every conv that touched the file, with
  functions/types/imports **added + removed**, tool_name, session_id, timestamp. This IS the feature timeline.
- `code_nodes` WHERE `file = ?` → current symbol inventory (functions, types) + provenance
  (`first_conv_id`, `last_conv_id`, `body_hash`).
- `code_edges` WHERE dst node in file → callers (who depends on this file).
- **tests link**: `code_evolution` rows where `file_path` matches `*_test.rs` / `tests/` / `test_*`
  AND share a `session_id` with edits to the target file → "tests written alongside this file."
- optional semantic layer: keep FTS5 as a *secondary* enrichment, not the primary lookup.

Output = immutable per-file dossier:
```
FILE LEDGER: csr-engine/src/extraction/ast_analysis.rs
  symbols now: extract_code_context, analyze_code, func_kinds (+8)  [code_nodes]
  timeline:
    16d conv_9f313ff  +anchors  fns +extract_name_from_def           [code_evolution]
    125d conv_cee5074 Phase 4 tree-sitter integration  fns +analyze_code
  callers: extraction/mod.rs, engine.rs (enrich pipeline)            [code_edges]
  tests touched same session: tests/integration.rs (AST cases)
```

This makes `search_by_file` the strongest, most *honest* tool in CSR — deterministic, no
score-fuzz, survives the "loses to grep" critique because it isn't competing on semantics. It is
the file-centric face of the same graph.

## 9. Hook injection — ranked slice (the payoff)

**Principle:** graph lives in SQLite; the hook injects a *query result*, not the graph.

- **SessionStart** (`session_start.rs` / `session_briefing.rs`): top-K highest-rank nodes for the
  project + their last-change provenance. ≤300 tokens. Framed as history (existing pattern).
- **UserPromptSubmit** (`prompt_submit.rs`): parse symbols/files named in the prompt + the active
  edited files (from `code_evolution`), pull their 1-hop neighborhood, rank-prune to ≤500 tokens,
  inject. Reuses existing stdout-injection + token-budget formatter (`injection/formatter.rs`).

Slice format (compact, deterministic):
```
CODE GRAPH (history): dispatch_hook [hooks/mod.rs] ← called by 6 · last changed conv_be… (catch-all wrapper, Codex C-1)
  calls → enrich_conversation, sanitize_input
  callers ← session_start, stop, post_tool_use
```

## 10. Eval — `eval --codegraph` (eval/)

Gate thresholds (block release if unmet):
- resolution_rate ≥ 0.70 on this repo's Rust.
- PageRank deterministic (same input → same top-20 order).
- injection slice ≤ 500 tokens, build for one file < 50 ms.
- `csr_code_graph` p95 < 5 ms (consistent with existing search SLA).
- round-trip: edit a fn → PostToolUse → `callers` query reflects it.

## 12. Risks / decisions

- **Resolver accuracy** — name-based, not scope-graph. Accept ambiguity; design hides it behind
  rank (ambiguous defs still rank). Future: swap `resolver.rs` for tree-sitter-stack-graphs behind
  same fn signature.
- **Cross-language calls** — out of scope (each fragment single-lang).
- **Graph size** — repo-scale (10²–10⁴ nodes). SQLite + in-memory PageRank trivially handles it.
- **Determinism** — required for eval + injection cache. Sort everything; no HashMap iteration order
  leaking into output.
- **Conversation provenance is the moat** — do not drop `conv_id`/`session_id` from any row.

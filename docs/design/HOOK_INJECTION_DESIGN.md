# Hook Injection Design - Narrative & Evaluation Context

**Feature Branch**: `feature/narrative-eval-hook-injection` (POST v7.0.0 release)
**Priority**: Medium
**Complexity**: Low
**Estimated Effort**: 2-3 hours

---

## 🎯 Objective

Automatically inject the **last generated narrative and evaluation** into the conversation context at appropriate points using Claude Code hooks, providing immediate feedback about what was learned and how the session was rated.

---

## 📋 Use Case

**Current Behavior**:
```
User: "Fix docker performance issues"
[... conversation happens ...]
[Session ends]
# Narrative and evaluation generated in background
# User never sees the evaluation or narrative
```

**Desired Behavior**:
```
User: "Fix docker performance issues"
[... conversation happens ...]
[Session ends]

🎯 Session Summary (Auto-generated):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📝 Narrative Generated:
   Problem: Docker volume mounts causing 73% slower builds
   Solution: Added :cached flag to volume mounts
   Outcome: ✅ Build time: 45s → 13s

⭐ Session Quality: 8.5/10
   ✅ Root cause identified correctly
   ✅ Minimal, targeted fix applied
   ✅ Outcome validated with metrics

💡 Key Learnings:
   • macOS Docker volumes need :cached for performance
   • Always measure before/after for optimization
   • :cached safe for source code, not databases
```

## 🔍 Hook Selection Analysis

Based on the Claude Code hooks reference, here are the candidates:

### Option 1: **SessionEnd Hook** ✅ RECOMMENDED

**When it fires**: When Claude Code session ends

**Advantages**:
- ✅ Natural summary point (end of session)
- ✅ Narrative/eval definitely generated by this point
- ✅ User sees summary before closing terminal
- ✅ Can show cost/time metrics for entire session
- ✅ Non-intrusive (doesn't interrupt workflow)

**Disadvantages**:
- ❌ Only shows at session end (not during)
- ❌ User might close terminal before seeing it

**Use Case**: Show session-wide summary with narrative and eval

**Matcher**: N/A (SessionEnd doesn't use matchers)

**Example Hook Configuration**:
```json
{
  "hooks": {
    "SessionEnd": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "$CLAUDE_PROJECT_DIR/.claude/hooks/session-summary.py"
          }
        ]
      }
    ]
  }
}
```

---

### Option 2: **Stop Hook** (Alternative)

**When it fires**: When Claude finishes responding (not interrupted)

**Advantages**:
- ✅ Shows after each major task completion
- ✅ More frequent feedback
- ✅ Can inject context for next turn

**Disadvantages**:
- ❌ Fires multiple times per session (noisy)
- ❌ Narrative might not be generated yet
- ❌ Interrupts workflow with frequent summaries

**Use Case**: Real-time notification when narrative generated

**Example**: "✨ Narrative generated! Search quality improved by 9.3x"

---

### Option 3: **PostToolUse Hook with Custom Trigger** (Advanced)

**When it fires**: After specific tool calls complete

**Advantages**:
- ✅ Can trigger on specific events (e.g., after Write/Edit)
- ✅ Precise control over when to inject

**Disadvantages**:
- ❌ Complex logic needed to determine when session complete
- ❌ Might not align with narrative generation timing

**Use Case**: Advanced users who want fine-grained control

---

## ✅ Recommended Approach: SessionEnd Hook

**Why SessionEnd?**
1. Narratives and evaluations are generated **after** the session ends
2. Perfect timing to show what was learned
3. Non-intrusive (doesn't interrupt active work)
4. Natural summary point

## 🏗️ Implementation Design

### File Structure
```
.claude/hooks/
├── session-summary.py          # Main hook script
├── narrative-fetcher.py         # Fetches latest narrative from Qdrant
└── eval-fetcher.py              # Fetches latest evaluation from Qdrant
```

### Hook Script: `session-summary.py`

```python
#!/usr/bin/env python3
"""
SessionEnd hook to inject narrative and evaluation summary.

Input (via stdin):
{
  "session_id": "abc123",
  "transcript_path": "~/.claude/projects/.../conversation.jsonl",
  "hook_event_name": "SessionEnd",
  "reason": "exit"
}

Output (stdout):
Formatted summary of narrative and evaluation
"""

import json
import sys
from pathlib import Path
from datetime import datetime

# Add CSR modules to path
sys.path.insert(0, str(Path.home() / ".claude-self-reflect"))

from qdrant_client import QdrantClient

def get_latest_narrative(conversation_id: str) -> dict:
    """Fetch latest narrative from Qdrant."""
    try:
        client = QdrantClient(url="http://localhost:6333")

        # Search for this conversation's narrative
        results = client.scroll(
            collection_name="v3_all_projects",
            scroll_filter={
                "must": [
                    {
                        "key": "conversation_id",
                        "match": {"value": conversation_id}
                    }
                ]
            },
            limit=1
        )

        if results and results[0]:
            return results[0][0].payload
        return None

    except Exception as e:
        return None


def get_latest_evaluation(conversation_id: str) -> dict:
    """Fetch latest evaluation from Qdrant."""
    try:
        client = QdrantClient(url="http://localhost:6333")

        results = client.scroll(
            collection_name="ground_truth_evals",
            scroll_filter={
                "must": [
                    {
                        "key": "conversation_id",
                        "match": {"value": conversation_id}
                    }
                ]
            },
            limit=1
        )

        if results and results[0]:
            return results[0][0].payload
        return None

    except Exception as e:
        return None


def format_summary(narrative: dict, evaluation: dict) -> str:
    """Format narrative and evaluation as readable summary."""

    lines = []
    lines.append("")
    lines.append("🎯 Session Summary (Auto-generated)")
    lines.append("━" * 60)

    # Narrative section
    if narrative:
        lines.append("📝 What We Accomplished:")

        # Extract problem-solution from narrative
        problem = narrative.get("problem", "N/A")
        solution = narrative.get("solution_approach", "N/A")
        outcome = narrative.get("validation_outcome", {})

        lines.append(f"   Problem: {problem[:100]}...")
        lines.append(f"   Solution: {solution[:100]}...")

        status = outcome.get("status", "unknown")
        status_emoji = "✅" if status == "success" else "⚠️"
        lines.append(f"   Outcome: {status_emoji} {outcome.get('description', 'N/A')[:80]}...")
    else:
        lines.append("📝 Narrative: Generating in background...")

    lines.append("")

    # Evaluation section
    if evaluation:
        scores = evaluation.get("scores", {})
        overall = scores.get("overall_grade", 0)

        lines.append(f"⭐ Session Quality: {overall * 10:.1f}/10")

        # Success points
        successes = evaluation.get("key_success_points", [])
        if successes:
            lines.append("   Strengths:")
            for success in successes[:2]:  # Top 2
                lines.append(f"   ✅ {success.get('achievement', 'N/A')}")

        # Insights
        insights = narrative.get("key_insights", []) if narrative else []
        if insights:
            lines.append("")
            lines.append("💡 Key Learnings:")
            for insight in insights[:3]:  # Top 3
                lines.append(f"   • {insight}")
    else:
        lines.append("⭐ Evaluation: Generating in background...")

    # Cost/time (if available)
    if narrative:
        cost = narrative.get("processing_cost", 0.027)
        time = narrative.get("processing_time_seconds", 120)
        lines.append("")
        lines.append(f"📊 Cost: ${cost:.3f} | Processing: {time / 60:.1f} min")

    lines.append("━" * 60)
    lines.append("")

    return "\n".join(lines)


def main():
    try:
        # Read input from stdin
        input_data = json.load(sys.stdin)

        # Extract conversation ID from transcript path
        transcript_path = Path(input_data["transcript_path"])
        conversation_id = transcript_path.stem  # Filename without extension

        # Fetch narrative and evaluation
        narrative = get_latest_narrative(conversation_id)
        evaluation = get_latest_evaluation(conversation_id)

        # Format and print summary
        summary = format_summary(narrative, evaluation)
        print(summary)

        # Exit successfully
        sys.exit(0)

    except Exception as e:
        # Silent failure - don't interrupt user workflow
        sys.exit(0)


if __name__ == "__main__":
    main()
```

```bash
# Create hooks directory
mkdir -p ~/.claude-self-reflect/hooks

chmod +x ~/.claude-self-reflect/hooks/session-summary.py
```

### Step 2: Update CLI Command
```javascript
// installer/cli.js

async function configureNarratives(options) {
  const { enableSessionSummary } = options;

  if (enableSessionSummary) {
    // Add SessionEnd hook to settings.json
    const settingsPath = path.join(os.homedir(), '.claude/settings.json');
    const settings = JSON.parse(fs.readFileSync(settingsPath, 'utf8'));

    if (!settings.hooks) settings.hooks = {};
    if (!settings.hooks.SessionEnd) settings.hooks.SessionEnd = [];

    settings.hooks.SessionEnd.push({
      hooks: [{
        type: "command",
        command: "python3 ~/.claude-self-reflect/hooks/session-summary.py",
        timeout: 5
      }]
    });

    fs.writeFileSync(settingsPath, JSON.stringify(settings, null, 2));
    console.log('✅ Session summary enabled');
  }
}
```

## 🔒 Security Considerations

1. **Timeout**: 5-second limit prevents hanging
2. **Silent Failure**: Script exits gracefully if Qdrant unavailable
3. **No File Writes**: Read-only operation
4. **Sandbox Safe**: Uses existing Qdrant connection only

---

## 📊 Performance Impact

- **Hook Execution**: < 500ms (Qdrant scroll query)
- **Network**: Local Qdrant only (http://localhost:6333)
- **CPU**: Minimal (JSON parsing + formatting)
- **Memory**: < 1MB

## 🔄 Alternative Approaches Considered

### Real-time Notification (Stop Hook)
**Pros**: Immediate feedback when narrative generated
**Cons**: Too frequent, interrupts workflow
**Decision**: Not recommended for v1

### Statusline Integration
**Pros**: Always visible in terminal
**Cons**: Limited space, hard to show full summary
**Decision**: Use sessionEnd for detailed summary, statusline for progress

### Email Summary
**Pros**: Asynchronous, doesn't interrupt
**Cons**: Requires email configuration, added complexity
**Decision**: Out of scope for v1

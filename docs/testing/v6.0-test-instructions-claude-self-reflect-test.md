## Test Scenarios

### 1. Memory Tool End-to-End Flow

**Scenario**: Store → Search → Retrieve workflow
```python
# 1. Store pattern to memory
await store_to_memory(
    ctx,
    path="patterns/v6-test.md",
    content="# v6.0 Test Pattern\n\nHybrid search validation",
    also_reflect=True
)

# 2. Search via Memory Tool
memory_results = await search_memory(ctx, "v6.0 Test Pattern")
assert "patterns/v6-test.md" in memory_results

# 3. Search via hybrid search
hybrid_results = await csr_reflect_on_past(ctx, "v6.0 Test Pattern")
assert "Memory Tool" in hybrid_results or "memory" in hybrid_results.lower()

# 4. Retrieve full content
content = await view_memory(ctx, "patterns/v6-test.md")
assert "Hybrid search validation" in content
```

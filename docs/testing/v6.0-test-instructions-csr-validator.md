### 2. Security Validation

**Critical: Path Traversal Prevention**

Run security test suite:
```bash
cd mcp-server
python -m pytest tests/test_memory_security.py -v
```

**Expected**: All 21 tests PASS, including:
- Parent directory traversal blocked (../)
- Absolute path access blocked (/etc/passwd)
- Symlink escape blocked
- Windows drive access blocked (C:\\)
- URL-encoded traversal blocked
- Null byte injection blocked
- Unicode traversal blocked

**Validation**: Check logs for security violations:
```python

```

### 3. Hybrid Search Integration

**Test: Memory Tool Priority**
```python
# Step 1: Store high-quality pattern to Memory Tool
await store_to_memory(
    ctx,
    path="patterns/auth-best-practice.md",
    content="# Authentication Best Practice\n\nAlways use bcrypt for passwords",
    category="patterns"
)

# Step 2: Also store to Qdrant
await store_reflection(ctx, "Authentication best practice: use bcrypt", tags=["security", "auth"])

# Step 3: Search - Memory Tool results should appear first
result = await csr_reflect_on_past(ctx, "authentication best practices")

# Verify hybrid search indicators
assert "from Memory Tool" in result or "Memory:" in result
# Memory results should have high scores (0.95)
```

**Test: File Size Limits**
```python

result = await search_memory(ctx, "x")
# Check logs for: "Skipping large file"
```

### 5. Enhanced Metadata Validation

**Test: memory_references Tracking**
```python
# Run metadata extraction on conversation with AST-grep analysis
metadata = MetadataExtractor().extract_metadata_from_file("conversation.jsonl")

# Check for memory_references field
assert "memory_references" in metadata
assert isinstance(metadata["memory_references"], list)

    assert len(metadata["memory_references"]) > 0
```

**Test: pattern_frequency Counting**
```python

       "anti_patterns" in metadata["pattern_frequency"]
```

**Test: context_importance Calculation**
```python
metadata = MetadataExtractor().extract_metadata_from_file("conversation.jsonl")

assert 0.0 <= metadata["context_importance"] <= 1.0

```

## Known Issues & Limitations

1. **Async I/O**: Memory Tool uses sync file I/O (acceptable for small files, enhancement planned for v6.1)
2. **URL Encoding**: Some URL-encoded paths resolve to "file not found" instead of explicit security error (still secure)
3. **File Size**: 1MB limit for search (prevents OOM, but very large memory files won't be searchable)
